# Cozy Budget

A cozy 2.5D house where every monthly bill is an object you can tap, and savings grow in a garden outside.

**Live demo:** https://invert-able.com/cozy.budget/

- Bills throb with a glow ring and a coin badge: green when on budget, coral when over.
- Tap an item to zoom in and open its bill card.
- Each garden row is a savings goal. Hitting the monthly target plants 6 seeds; saving extra fills the row.
- Sep/Oct/Nov tabs switch months. Drag to turn, pinch or scroll to zoom.

This is a demo with a made-up sample budget. No real financial data is used.

Built with Three.js by Jordan Reeher / Invert LLC.
